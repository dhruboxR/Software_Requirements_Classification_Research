================================================================================
EXECUTIVE SUMMARY
================================================================================

This report documents the completed deep learning research stage of a software
Requirements Engineering thesis. The research problem is binary classification of
natural-language software requirements into Functional Requirements (FR) and
Non-Functional Requirements (NFR). A frozen, similarity-group-separated dataset
(D2 v1.1) contains 4,833 requirements, divided into 3,378 training records,
728 validation records and 727 sealed test records. All quantitative performance
results described in this report refer to the validation partition. The test
partition was not accessed in deep_learning_research Scripts 00–18.

Four neural baseline configurations (two TextCNN, two BiLSTM) and nine
fine-tuned transformer runs (DistilBERT, BERT-base and RoBERTa-base, each under
seeds 42, 17 and 29) were completed. DistilBERT obtained the highest observed
three-seed mean NFR F1, 0.8634 (sample standard deviation 0.0036), and the
highest mean macro-F1, 0.8975. The margin over BERT-base was small and should
not be treated as proof of statistical superiority. DistilBERT's original
seed-42 run attained NFR F1 = 0.8595 on 728 validation requirements, with
41 false positives and 28 false negatives.

Multi-seed prediction analysis showed that DistilBERT made identical predictions
on 678 of 728 validation requirements across all three seeds (93.13%). The
models shared 29 requirements that all nine transformer runs misclassified
relative to original labels. Forty-three requirements were prioritized for
qualitative review. An AI-assisted assessment agreed with original labels on
11 cases, disagreed on 25, and marked 7 as uncertain. Because the review cases
were selected precisely for model errors, and because the review was conducted
by an AI assistant rather than independent human annotators, these observations
cannot establish a prevalence of annotation mistakes in the dataset.

The selected final model is the existing DistilBERT seed-42 checkpoint, with
maximum input length 96, FR class ID 0, NFR class ID 1, and a fixed NFR
probability threshold of 0.5. Script 18 hashed and froze the original
checkpoint and its selection metadata. A separate final_model workspace has
since verified a copied checkpoint and tokenizer, but final test evaluation
has NOT been run at the time of this report.

1. RESEARCH AIM, SCOPE AND EVALUATION DISCIPLINE
================================================================================

Research aim:
  Evaluate deep learning architectures for classifying software requirement
  statements as FR or NFR, with particular attention to minority-class NFR
  performance, variability across random seeds, and persistent errors.

Primary development-stage metric:
  NFR F1 score, treating NFR as the positive class.

Supplementary metrics:
  NFR precision; NFR recall; macro-F1; balanced accuracy; accuracy; and,
  where computed, average precision (AP) and ROC AUC.

Interpretation of confusion matrix entries:
  TN = original FR predicted FR.
  FP = original FR predicted NFR.
  FN = original NFR predicted FR.
  TP = original NFR predicted NFR.

Data boundaries:
  Model development and best-epoch choices used the training and validation
  partitions. The test partition was held back for an eventual one-time final
  assessment. Extensive validation reuse is a real limitation: a sealed test
  does not remove selection optimism introduced on validation data.

Specific research boundary:
  This report covers the 'deep_learning_research' project through Script 18,
  and briefly notes the separate final_model Script 00 integrity verification.
  Prior classical ML development is context, not reanalyzed from source files.

8. SCRIPT 08: PAIRED TRANSFORMER COMPARISONS
================================================================================

Inputs:
  Matched validation predictions from DistilBERT, BERT-base, RoBERTa-base
  seed-42 runs. Required ID and label alignment was verified.

Method:
  Exact McNemar tests on discordant correctness outcomes and 2,000
  similarity-group bootstrap resamples for NFR F1 and recall differences.
  728 requirements spanning 694 validation similarity groups.

Paired findings (model A minus model B):

  DistilBERT vs BERT-base:
    Differing predictions: 38.
    Correct only for DistilBERT: 20; only for BERT: 18.
    Exact McNemar p = 0.871415.
    NFR F1 difference: +0.0018, 95% group-bootstrap CI [-0.0242, +0.0258].
    NFR recall difference: -0.0126, CI [-0.0496, +0.0220].

  DistilBERT vs RoBERTa-base:
    Differing predictions: 39.
    Correct only for DistilBERT: 19; only for RoBERTa: 20.
    Exact McNemar p = 1.0.
    NFR F1 difference: +0.0060, CI [-0.0193, +0.0319].
    NFR recall difference: +0.0544, CI [+0.0205, +0.0909].

  BERT-base vs RoBERTa-base:
    Differing predictions: 45.
    Correct only for BERT: 21; only for RoBERTa: 24.
    Exact McNemar p = 0.765992.
    NFR F1 difference: +0.0043, CI [-0.0223, +0.0329].
    NFR recall difference: +0.0669, CI [+0.0300, +0.1066].

Interpretation:
  No NFR F1 advantage was established by these seed-42 paired comparisons.
  RoBERTa's lower NFR recall relative to the other two was visible in the
  exploratory intervals, without multiplicity correction. The common
  validation data and single training seeds limit broader inference.

19. LIMITATIONS, THREATS TO VALIDITY AND REPORTING RULES
================================================================================

A. Annotation uncertainty
   Labels in the frozen dataset were retained even when the AI-assisted
   review questioned them. Model errors are errors against those original
   labels; an alternative AI label is not established ground truth.

B. AI-assisted review dependence
   The AI reviewer may share biases with transformer classifiers and is not
   an independent human annotator. Five original labels were previously
   exposed. Claims of fully blind human adjudication would be incorrect.

C. Selection bias in error review
   The 43 reviewed cases were not randomly sampled. They were chosen for
   persistent model errors. Do not extrapolate 25 disagreements to the entire
   dataset or estimate label-error prevalence from this sample.

D. Repeated validation use
   Validation data influenced checkpoint selection, model comparisons,
   architectural choice and review selection over many experiments. This
   may create optimistic development estimates despite a sealed test split.

E. Limited random-seed coverage
   Three seeds describe initial sensitivity to training stochasticity, not
   a comprehensive variability distribution. Standard deviations are
   descriptive over three runs, not independent test-set uncertainties.

F. Generalization unit
   The dataset was separated by similarity groups, but project-level and
   source-level independence were not proven. Avoid claiming robust
   generalization to entirely unseen projects or organizations.

G. Limited model families/configurations
   Evaluated architectures and hyperparameter choices are finite. No
   general claim about all CNNs, LSTMs or transformers follows.

H. Threshold and ensemble handling
   Threshold fixed at 0.5 in final selection. Validation majority-vote
   performance was exploratory; an ensemble is not the final selected method.

I. Model and file reproducibility
   Script 18 records the actual checkpoint hashes. Refer to its original
   JSON rather than restating an unverified hash. The external checkpoint
   copy was checked in final_model Script 00.

J. Test-set boundary
   At the time of this report, test predictions and scores have not been
   produced. No final accuracy, NFR F1, confusion matrix or ROC AUC can be
   reported for held-out test requirements yet.

K. Statistical interpretation
   The seed-42 paired NFR F1 confidence intervals crossed zero; one should
   not declare established comparative F1 superiority. Exploratory recall
   differences and repeated analyses require caution about multiplicity.
